# 北京求职雷达

匿名公开的岗位级信息看板，重点关注京考、国考、北京定向选调与优培、北京事业单位，以及工作地点在北京的央国企岗位。

## 数据原则

- 一条公开记录必须对应一个具体岗位或职位表中的唯一一行。
- 第三方渠道只负责发现线索，公开字段必须回到官方来源核验。
- 公考和选调岗位必须结合私有资格档案完成全部硬条件校验，只有确认可报才发布。
- 央国企岗位准确区分“符合”“需要确认”和“谨慎尝试”，不把优先条件当成符合条件。
- 公开仓库不保存姓名、学校、联系方式、照片、出生信息、籍贯或详细荣誉等个人资料。

岗位数据位于 `data/opportunities.json`。提交前运行：

```bash
node scripts/validate-data.mjs
node scripts/check-privacy.mjs
```

GitHub Pages 只有在数据门禁和匿名检查全部通过后才会部署。
